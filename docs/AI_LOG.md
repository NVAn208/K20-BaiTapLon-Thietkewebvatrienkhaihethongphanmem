# Khai báo AI
## Mục đích sử dụng
- Sử dụng để soát lỗi thành phần code 
- Nâng cấp hệ thống giao diện người xem
- Thay đổi nhỏ cho giao diện trở nên sinh đọng và đẹp hơn
## AI hỗ trợ
- AI đã hỗ trợ phần code vẽ hình minh họa trong ket-qua.html
- hỗ trợ nâng cấp giao diện trong css
- hỗ trợ đánh dấu lỗi chính tả trong code ở đâu để sửa lại
## Giữ / sửa
### Giữ
- Giữ thay đổi nền backgroud
- giữ lại hình vẽ dấu tích hoàn thành ở ket-qua.html
- Nâng cấp giao điện người xem trở nên hấp dẫn, dễ nhìn hơn.
### Sửa
- Sửa những dòng code lỗi chính tả hoặc sai cú pháp được AI đánh dấu 
- Sửa màu backgroud do AI chọn
## Cách tự kiểm tra
- Sau mỗi lần sửa em cho code chạy trực tiếp trên trình duyệt hoặc sử dụng extension:live server của visual studio code để kiểm tra một lượt, nếu mắc lỗi ở phần nào thì xem thành phần bị lỗi ở đâu và đánh dấu để sau một lượt kiểm tra có thể nắm bắt được lỗi ở đâu và sửa trực tiếp ở đó.
